# Product Card App

This project is a simple web application that displays product cards using data fetched from an API. It includes functionality for basic CRUD (Create, Read, Update, Delete) operations on the products.

## Features
- **Display Products**: Dynamically render product cards with:
  - **Title**
  - **Price**
  - **Description**
  - **Image**
- **CRUD Operations**:
  1. **Read**: Fetch and display 20 products from the API.
  2. **Update**: Update the product title via a button.
  3. **Delete**: Delete a product by clicking the delete button.
  4. **Create**: Add a new product using a `POST` request.

## File Structure
- **`index.html`**: HTML structure for the application.
- **`app.js`**: Contains logic for:
  - Fetching data from the API.
  - Rendering product cards.
  - Handling CRUD operations.
-  CSS styles for a modern and clean card layout.
